## Диаграмма процесса входа

::uml::
actor Пользователь
participant "Веб-приложение" as App
participant "Сервис авторизации" as Auth

Пользователь -> App : email и пароль
App -> Auth : проверить учётные данные
alt данные верны
  Auth --> App : токен
  App --> Пользователь : главная страница
else данные неверны
  Auth --> App : ошибка
  App --> Пользователь : сообщение об ошибке
end
::end-uml::
